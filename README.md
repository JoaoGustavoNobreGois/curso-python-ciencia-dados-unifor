# Curso Introdutório de Python para Ciência de Dados (T326 - UNIFOR)

Este repositório contém os materiais do **Curso Introdutório de Python para Ciência de Dados**, desenvolvido como parte da atividade extensionista da disciplina **Ciência de Dados (T326)** da **Universidade de Fortaleza (UNIFOR)**.

O objetivo do projeto é democratizar o acesso ao conhecimento em programação e análise de dados, oferecendo um curso introdutório voltado para estudantes e profissionais interessados em iniciar na área de **Ciência de Dados utilizando Python**.

---

## 🎯 Objetivo do Curso

O curso tem como objetivo apresentar os **fundamentos da programação em Python aplicados à análise de dados**, permitindo que os participantes desenvolvam habilidades básicas em:

- Programação em Python
- Manipulação de dados
- Visualização de dados
- Análise exploratória de dados (EDA)

Ao final do curso, espera-se que os participantes sejam capazes de trabalhar com datasets reais, extrair informações relevantes e comunicar insights de forma clara.

---

## 👥 Público-Alvo

Este curso foi desenvolvido para:

- Estudantes do ensino médio ou técnico
- Estudantes de graduação
- Profissionais em transição de carreira
- Pessoas interessadas em iniciar na área de ciência de dados

Não é necessário conhecimento prévio em programação.

---

## 📚 Estrutura do Curso

O curso está organizado em **4 módulos principais**:

### Módulo 1 — Fundamentos de Python

Introdução à programação utilizando Python.

**Conteúdos abordados:**

- Introdução à programação
- Sintaxe básica do Python
- Variáveis e tipos de dados
- Estruturas condicionais (if, else, elif)
- Estruturas de repetição (for e while)
- Estruturas de dados (listas, tuplas e dicionários)
- Boas práticas de programação
- Introdução ao Jupyter Notebook

---

### Módulo 2 — Manipulação de Dados

Introdução à análise de dados utilizando a biblioteca **Pandas**.

**Conteúdos abordados:**

- Introdução ao Pandas
- Estrutura de DataFrames
- Leitura de arquivos CSV e Excel
- Filtragem e seleção de dados
- Tratamento de valores nulos
- Transformação e organização de dados
- Estatística descritiva básica

---

### Módulo 3 — Visualização de Dados

Apresentação de técnicas de visualização para análise de dados.

**Conteúdos abordados:**

- Fundamentos de visualização de dados
- Biblioteca Matplotlib
- Biblioteca Seaborn
- Gráficos de barras
- Gráficos de linha
- Histogramas
- Gráficos de dispersão
- Boas práticas de comunicação visual

---

### Módulo 4 — Análise Exploratória de Dados (EDA)

Aplicação prática dos conhecimentos adquiridos.

**Conteúdos abordados:**

- Definição de problemas de análise
- Formulação de perguntas analíticas
- Exploração de datasets
- Identificação de padrões
- Visualização para geração de insights
- Comunicação de resultados

## ▶️ Como Executar os Notebooks

### Opção 1 — Google Colab (recomendado)

1. Acesse a pasta `notebooks` no repositório
2. Abra o arquivo `.ipynb` desejado
3. Clique no botão "Open in Colab" (se disponível) ou faça o download e faça upload no Google Colab
4. Execute o notebook diretamente no **Google Colab**

### Opção 2 — Execução Local

**1. Instalar Python**

Instale Python 3.9 ou superior a partir do site oficial: python.org

**2. Instalar dependências**

Abra o terminal ou prompt de comando e execute:

pip install notebook pandas matplotlib seaborn

**3. Executar Jupyter Notebook**

No terminal, navegue até a pasta do projeto e execute:

jupyter notebook

Abra o notebook desejado dentro da pasta `notebooks`.
