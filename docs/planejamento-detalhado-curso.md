# Planejamento Detalhado - Curso Introdutório de Python para Ciência de Dados

## Informações Gerais

- **Disciplina:** Ciência de Dados (T326)
- **Instituição:** Universidade de Fortaleza (UNIFOR)
- **Carga Horária Total:** 20 horas
- **Duração:** 4 semanas (5 horas por semana)
- **Formato:** Híbrido (2 horas teóricas + 3 horas práticas por semana)

## Estrutura Cronograma

### Semana 1: Fundamentos de Python (5 horas)
- **Dia 1 (2h):** Introdução à programação e sintaxe Python
- **Dia 2 (3h):** Estruturas de controle e dados básicas

### Semana 2: Manipulação de Dados (5 horas)
- **Dia 1 (2h):** Introdução ao Pandas e DataFrames
- **Dia 2 (3h):** Operações avançadas com Pandas

### Semana 3: Visualização de Dados (5 horas)
- **Dia 1 (2h):** Fundamentos e Matplotlib
- **Dia 2 (3h):** Visualizações avançadas com Seaborn

### Semana 4: Análise Exploratória (5 horas)
- **Dia 1 (2h):** Metodologia EDA e formulação de perguntas
- **Dia 2 (3h):** Projeto final e apresentação de resultados

## Objetivos de Aprendizagem por Módulo

### Módulo 1 - Fundamentos de Python
Ao final deste módulo, os alunos serão capazes de:
- Compreender conceitos básicos de programação
- Escrever código Python funcional
- Utilizar estruturas de controle de fluxo
- Manipular estruturas de dados básicas
- Resolver problemas simples usando algoritmos

### Módulo 2 - Manipulação de Dados
Ao final deste módulo, os alunos serão capazes de:
- Importar e exportar dados de diferentes formatos
- Limpar e preprocessar datasets
- Realizar filtragens e transformações
- Calcular estatísticas descritivas
- Combinar diferentes fontes de dados

### Módulo 3 - Visualização de Dados
Ao final deste módulo, os alunos serão capazes de:
- Escolher o tipo de gráfico adequado para cada situação
- Criar visualizações claras e informativas
- Customizar gráficos para melhor comunicação
- Aplicar princípios de design visual
- Identificar padrões através de visualizações

### Módulo 4 - Análise Exploratória
Ao final deste módulo, os alunos serão capazes de:
- Formular perguntas analíticas relevantes
- Explorar datasets de forma sistemática
- Identificar tendências e anomalias
- Comunicar insights de forma eficaz
- Documentar todo o processo de análise

## Metodologia de Ensino

- **Aprendizagem Ativa:** Os alunos participam ativamente das aulas práticas
- **Problem-Based Learning:** Resolução de problemas reais

### Recursos Didáticos
- **Notebooks Jupyter:** Para aulas práticas

- **Vídeos de Apoio:** Para revisão de conceitos

## Sistema de Avaliação

### Componentes de Avaliação
1. **Participação em Aula (20%)**
   - Engajamento nas discussões
   - Contribuição nas atividades em grupo

2. **Exercícios Práticos (30%)**
   - Completude das soluções
   - Qualidade do código
   - Documentação adequada

3. **Projeto Final (40%)**
   - Análise completa de um dataset
   - Qualidade das visualizações
   - Clareza na comunicação dos resultados

4. **Autoavaliação (10%)**
   - Reflexão sobre o processo de aprendizagem
   - Identificação de pontos de melhoria

### Critérios de Avaliação do Projeto Final
- **Complexidade da Análise (25%)**
- **Qualidade Técnica (25%)**
- **Comunicação dos Resultados (25%)**
- **Inovação e Criatividade (25%)**

## Plano de Aula Detalhado

### Aula 1: Introdução à Programação (2h)
**Objetivos:**
- Apresentar o curso e expectativas
- Introduzir conceitos básicos de programação
- Configurar ambiente de desenvolvimento

**Conteúdo:**
- O que é programação e por que aprender Python
- História e aplicações do Python
- Instalação e configuração do ambiente
- Primeiro programa: "Hello, World!"
- Variáveis e tipos básicos

**Atividades:**
- Ice breaker sobre experiências com tecnologia
- Instalação guiada do Python e Jupyter
- Exercício: calcular média de notas

### Aula 2: Estruturas de Controle (3h)
**Objetivos:**
- Compreender estruturas condicionais
- Dominar laços de repetição
- Aplicar estruturas de dados básicas

**Conteúdo:**
- Estruturas if/else/elif
- Laços for e while
- Listas, tuplas e dicionários
- Funções básicas
- Boas práticas de programação

**Atividades:**
- Exercício: sistema de notas
- Desafio: jogo de adivinhação
- Projeto mini: calculadora de IMC

### Aula 3: Introdução ao Pandas (2h)
**Objetivos:**
- Compreender a estrutura do Pandas
- Importar dados de diferentes fontes
- Realizar operações básicas com DataFrames

**Conteúdo:**
- O que é Pandas e por que usar
- Estrutura de Series e DataFrames
- Leitura de arquivos CSV e Excel
- Inspeção inicial dos dados
- Seleção e filtragem básica

**Atividades:**
- Exploração de dataset de vendas
- Exercício: análise de dados de alunos
- Desafio: encontrar padrões em dados

### Aula 4: Operações Avançadas com Pandas (3h)
**Objetivos:**
- Dominar técnicas de manipulação de dados
- Tratar valores ausentes
- Realizar agregações e transformações

**Conteúdo:**
- Tratamento de valores nulos
- Agrupamento e agregação
- Merge e join de DataFrames
- Transformação de dados
- Estatísticas descritivas

**Atividades:**
- Limpeza de dataset sujo
- Análise de dados de vendas por região
- Projeto: análise de dados escolares

### Aula 5: Fundamentos de Visualização (2h)
**Objetivos:**
- Compreender princípios de visualização
- Criar gráficos básicos com Matplotlib
- Aplicar conceitos de design visual

**Conteúdo:**
- Importância da visualização de dados
- Tipos de gráficos e suas aplicações
- Introdução ao Matplotlib
- Gráficos de barras, linhas e dispersão
- Customização básica

**Atividades:**
- Análise crítica de visualizações
- Criação de primeiros gráficos
- Exercício: visualizar dados de temperatura

### Aula 6: Visualizações Avançadas (3h)
**Objetivos:**
- Dominar a biblioteca Seaborn
- Criar visualizações complexas
- Aplicar técnicas avançadas de design

**Conteúdo:**
- Introdução ao Seaborn
- Gráficos estatísticos
- Visualizações multivariadas
- Customização avançada
- Boas práticas de comunicação visual

**Atividades:**
- Análise exploratória visual
- Criação de dashboard simples
- Desafio: contar uma história com dados

### Aula 7: Metodologia EDA (2h)
**Objetivos:**
- Compreender o processo de análise exploratória
- Formular perguntas analíticas
- Planejar uma análise completa

**Conteúdo:**
- O que é Análise Exploratória de Dados
- Frameworks de EDA
- Formulação de hipóteses
- Documentação do processo
- Ética em análise de dados

**Atividades:**
- Brainstorming de perguntas analíticas
- Planejamento de projetos
- Discussão sobre ética em dados

### Aula 8: Projeto Final e Apresentação (3h)
**Objetivos:**
- Aplicar todos os conhecimentos adquiridos
- Desenvolver uma análise completa
- Comunicar resultados de forma eficaz

**Conteúdo:**
- Desenvolvimento do projeto final
- Revisão de conceitos importantes
- Preparação de apresentações
- Feedback dos projetos

**Atividades:**
- Desenvolvimento guiado do projeto
- Sessão de apresentações
- Feedback construtivo
- Celebração das conquistas

## Considerações Finais

Este curso foi desenhado para ser uma porta de entrada acessível e estimulante para o mundo da ciência de dados. A abordagem prática e contextualizada com problemas brasileiros busca tornar o aprendizado mais relevante e aplicável.

A estrutura modular permite flexibilidade para adaptações conforme o perfil da turma, enquanto a avaliação contínua garante que os objetivos de aprendizagem sejam alcançados de forma eficaz.

O sucesso desta iniciativa extensionista será medido não apenas pela competência técnica adquirida, mas principalmente pela capacidade dos participantes de aplicar esses conhecimentos para gerar valor em suas comunidades e carreiras profissionais.
